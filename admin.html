This page does not publish

Nothing you change here reaches evanemery.art. The site is a static build with no backend. Edits are written to localStorage in this browser only — they show up in your own preview and vanish on another machine, another browser, or after clearing site data.

To actually publish a change: edit it here, press Export works-data.js, drop the downloaded file into js/works-data.js in the deploy repo, run node tools/build.mjs, then commit and push. Cloudflare Pages redeploys on push.

Image uploads are not supported here. The old drag-and-drop image slots only worked inside the authoring runtime; on a static host they were read-only. Add images as files under assets/works/ and reference them from works-data.js.
